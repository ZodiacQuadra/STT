# STT - Unified Operations Portal

Unified Operations Portal for STT GDC (ST Telemedia Global Data Centres).

## Overview
A enterprise-grade portal featuring:
- Role-based Operations Experience (User & Administrator Views)
- Centralized Applications Catalog & Launcher with categorization and favorite pinning
- User Management & Azure AD Directory synchronization
- Administrative Audit Logs tracking system events and configuration changes
- User Profile management with detailed attributes and photo updating
- Seamless dual-theme support (Pure Black Dark Theme `#000000` & Refined Light Theme) adhering to the design system

## Tech Stack
- **Framework**: React 18, TypeScript, Vite
- **Styling**: SCSS Modules with CSS Design Tokens
- **Icons**: Bootstrap Icons

## Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
